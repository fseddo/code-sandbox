# Research briefs

Per-chapter research records produced by [`system-design-chapter-sourcer`](../../.claude/agents/system-design-chapter-sourcer.md)
and consumed by the lesson authors and auditors during a chapter build
(see [system-design-authoring.md](../features/system-design-authoring.md)).

They're kept, not scratch: a brief is the claim chain behind a chapter's pages, so an auditor — or a reader
who disputes something a year from now — can trace a statement back to the sources it came from. One file per
chapter, named `system-design-<chapter-slug>.md`.
